# PSYC*1010: Making Sense of Data in Psychological Research Lab Workbooks
This repository contains the source code for the lab workbooks accompanying the **PSYC*1010: Making Sense of Data in Psychological Research course, taught at the University of Guelph** by Bryan Hong. This content largely builds and adapts upon materials and resources from other statistics and programming educators, many of which are made publicly available.
